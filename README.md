# CUDA Ray Tracer

A GPU-accelerated ray tracer implemented in C++ and CUDA. The renderer supports recursive reflection, refraction (dielectrics), diffuse shading, custom primitive intersections and uses a Bounding Volume Hierarchy (BVH) accelerate ray-primitive intersection queries.

### Features:
- CUDA Kernel Acceleration: Parallelised pixel generation, shading and multi-sample anti-aliasing.
- Acceleration Structures: Uses a BVH hierarchy built on the CPU which is then flattened and traversed iteratively on the GPU using stack based traversal.
- Primitives:
  - Spheres
  - Quadrilaterals
  - Cuboids
  - Transformed instances of other shapes using rotation and translation
- Materials:
  - Lambertian (diffuse) using cosine weighted hemisphere sampling
  - Metallic surfaces with adjustable roughness and specular reflection
  - Dielectric materials implementing Snell's law, total internal reflection and Schlick's approximation for Fresnel reflectance
  - Diffuse light used as a lighting source
- Camera Control: Adjustable FOV and look-from and look-at positions

### Architecture Overview

```
src/
├── images/           # contains all images that need to be loaded to be use as textures for objects
├── sample_images/    # contains a few example images
├── aabb.cuh          # defines axis aligned bounding boxes for BVH structure
├── bvh.cuh           # contains main BVH logic for creating, flattening and checking intersection with the BVH
├── camera.cuh        # defines the 'camera' which captures the image generated by casting rays through the viewport
├── colour.h          # contains functions to write colours to the accumulation buffer while generating the image
├── cuboid.h          # contains all cuboid definition and intersection checks
├── device_maths.cuh  # contains random number generation functions and degrees to radians conversion
├── hittable.h        # defines the parent class for all objects that can be hit by rays and the record used to record information about a ray-hittable intersection.
├── image.h           # contains the definition of the image class used for creating object textures from images
├── image.cu          # contains the implementation of the image class
├── interval.h        # contains a definition for an interval used to represent a range of floating point numbers
├── main.cu           # scene configuration, BVH build pipeline, scene generation
├── mat3.cuh          # defines the representation and operations of a 3x3 matrix
├── material.cuh      # contains all material definition and scattering behaviour
├── quad.h            # contains all quadrilateral definition and intersection checks
├── ray.h             # defines the 'rays of light' that are cast out into the scene to mimic light hitting the camera
├── sphere.h          # contains all sphere definition and intersection checks
├── texture.h         # defines different textures which affect the way that lambertian materials return colour when hit
├── transform.cuh     # defines how primitives can be rotated and translated
└──  vec3.cuh         # defines the representation and operations of 3 dimensional vectors
```

### Key Implementation Details

1. Fixed-Stack BVH Traversal on GPU: The tree is flattened into a linear array before being copied to GPU memory. Each thread maintains a fixed-size local stack to avoid using expensive recursive calls.
2. Transformations using ray inversion: Rather than transforming complex objects, rays are transformed into the objects 'local space' using the inverse matrix then tested against axis-aligned objects, simplifying intersection logic, before transforming back to world space.
3. Random Number Generation: Uses PCG random number generator to generated stochastic samples across rays.
4. Uses Next Event Estimation involving casting shadow rays between ray-object intersection points and randomly generated points on diffuse light objects to more accurately capture the lighting in a scene while reducing noise and improving image clarity with a low number of samples per pixel.

### Build & Run

##### Prerequisites
- C++ Compiler: GCC 9+ / Clang 11+ / MSVC 2019+
- CUDA Toolkit: 11.0 or higher
- Build System: CMake 3.18+

```
# Clone the repository
git clone https://github.com/AdvayGoel/CUDA-Ray-tracer.git
cd CUDA-Ray-tracer

# Generate build files
cmake -S . -B build

# Compile the target
cmake --build build -j$(nproc)
```
##### Usage

| scene_id | scene description |
| --- | --- |
| 1 | Snowman surrounded by small balls of ice with varying reflectance |
| 2 | Small box of light on a red floor |
| 3 | Cornell box |
| 4 | Earth |
| 5 | A small globe resting on the corner of a wooden table in a large room with a glass window |

```
./build/raytracer > <image_filename>.ppm <scene_id>
```
Then open the image in any ppm viewer or convert to a png using 
```
ffmpeg -i <image_name>.ppm <image_name>.png
```
